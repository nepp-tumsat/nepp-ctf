# Web - Storage

ウェブブラウザには、クライアント側でデータを保存するための様々なメカニズムがあります。
その中でも代表的なものが**Web Storage API**です。

Web Storage APIには主に2つの種類があります：

1. **localStorage** - ブラウザを閉じても保持されるデータストレージ
2. **sessionStorage** - ブラウザのセッション中のみ保持されるデータストレージ

これらのストレージは、キーと値のペアでデータを保存します。
値はすべて文字列として保存されるため、オブジェクトを保存する場合はJSON形式に変換する必要があります。

## 開発者ツールでの確認方法

ブラウザの開発者ツールを使用して、ウェブサイトが保存しているストレージデータを確認できます：

1. F12キーまたは右クリック→検証で開発者ツールを開く
2. Application/Storageタブを選択
3. 左側のメニューからLocal StorageまたはSession Storageを選択
4. サイトのドメインを選択してデータを表示

## セキュリティの観点

Web Storageはクライアント側に保存されるため、機密情報や認証情報を平文で保存するべきではありません。
ユーザーは開発者ツールを使って簡単にデータを閲覧・編集できるため、重要なデータは適切に暗号化するか、
サーバー側で保管する必要があります。

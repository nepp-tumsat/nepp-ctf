# [Level2] ローカルストレージの確認

本HTMLページ <https://nepp-tumsat.github.io/nepp-ctf/web_storage_q1.html> にはフラグが隠されています。

ブラウザの開発者ツールを使用してローカルストレージを確認し、フラグを見つけてください。

## フラグ形式

`nepp{web-storage-q1-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}`

## ヒント

ブラウザの開発者ツールを開き、Application/Storageタブを確認してください。
Chromeの場合は「Application」タブ、Firefoxの場合は「Storage」タブにローカルストレージの情報が表示されます。

[Web Storage API - Web API | MDN](https://developer.mozilla.org/ja/docs/Web/API/Web_Storage_API)
